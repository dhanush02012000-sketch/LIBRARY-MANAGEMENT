# 🎓 Student Record Management System in C

A **menu-driven Student Record Management System** developed in **C programming** using a **singly linked list**, dynamic memory allocation, structures, file handling, searching, modification, deletion, and sorting techniques.

The project allows users to manage student records efficiently through a simple command-line interface.

---

## 📌 Project Overview

The Student Record Management System is a console-based C application designed to store and manage student information.

Each student record contains:

- Roll Number
- Student Name
- Percentage

The records are maintained dynamically using a **singly linked list**. The application provides options to add, delete, display, modify, save, load, and sort student records.

Student data is stored permanently in a text file named `student.txt`, allowing records to be loaded automatically when the program starts.

## ✨ Features

### 1. ➕ Add Student Record

The system allows the user to add a new student record.

The following information is stored:

- Roll Number
- Name
- Percentage

The roll number is automatically generated by finding the smallest available roll number.

Example:

```text
Generated Roll No: 1
Enter Name: Dhanush
Enter Percentage: 85.50

Record Added Successfully.
```

---

### 2. 🗑️ Delete Student Record

A student record can be deleted using:

- Roll Number
- Student Name

If multiple students have the same name, the program displays the matching records and asks for the roll number of the record to delete.

Example:

```text
R/r : Delete using Roll Number
N/n : Delete using Name

Enter Your Choice: R
Enter Roll No: 2

Record Deleted.
```

---

### 3. 📋 Display Student Records

The system displays all available student records in a formatted table.

Example:

```text
================================================
| Roll No  | Name                 | Percentage |
================================================

| 2        | Arun                 |      78.25 |
| 3        | Kumar                |      91.00 |
================================================
```

---

### 4. ✏️ Modify Student Record

Existing student records can be modified.

Records can be searched using:

- Roll Number
- Name
- Percentage

After finding the required record, the user can modify:

- Student Name
- Percentage

Example:

```text

| R/r : Search by Roll No                      |
| N/n : Search by Name                         |
| P/p : Search by Percentage                   |
================================================
```

---

### 5. 💾 Save Student Records

The current student records are stored in:

```text
student.txt
```

The program writes the following information:

```text
Roll Number
Name
Percentage
```

Example:

```text

3 Kumar 91.00
```

---

### 6. 📂 Load Student Records

When the application starts, it automatically attempts to read the existing records from `student.txt`.

This means the records do not have to be entered again every time the program is executed.

The program uses file handling functions such as:

```c
fopen()
fscanf()
fprintf()
fclose()
```

---

### 7. 🔤 Sort Student Records

The system provides two sorting options:

#### Sort by Name

Records are sorted alphabetically from:

```text
A → Z
```

#### Sort by Percentage

Records are sorted from:

```text
Highest → Lowest
```

The program temporarily stores linked-list node addresses in an array and rearranges those pointers for sorting.

### 8. 🚪 Exit Options

When the user chooses to exit, the program provides two options:

```text

E/e : Exit Without Saving
```

This allows the user to save the latest changes before closing the application.

```text
+------------+----------------+------------+--------+
```

# 🔧 Student Structure

The student record is defined in `student.h`:

```c
struct student
{
    int roll;
    char name[50];
    float percent;
    struct student *next;
};
```

### Members

| Member | Data Type | Purpose |
|--------|-----------|---------|
| `roll` | `int` | Stores student roll number |
| `name` | `char[50]` | Stores student name |
| `percent` | `float` | Stores percentage |
| `next` | pointer | Points to the next student node |

# ⚙️ How the Program Works

## Step 1: Program Initialization

The program starts with:

```c
struct student *head = NULL;
```

The `head` pointer represents the first node of the linked list.

---

## Step 2: Load Existing Data

The program calls:

```c
stud_load();
```

If `student.txt` exists, the stored records are loaded into dynamically allocated linked-list nodes.

If the file does not exist, the program starts with an empty list.

---

## Step 3: User Selects an Operation

The main menu accepts a character from the user.

For example:

```text
A → Add
D → Delete
S → Show
M → Modify
V → Save
T → Sort
E → Exit
```

A `switch` statement is used to call the corresponding function.

# 🧠 Linked List Implementation

Dynamic memory allocation is used when adding a student:

```c
struct student *temp =
    (struct student *)malloc(sizeof(struct student));
```

The new node is connected to the existing linked list.

For example:

```text
HEAD
 ↓
Student 1 → Student 2 → Student 3 → NULL
```

When deleting a node, the links are updated and the memory is released using:

```c
free(temp);
```

# ⚠️ Current Limitations

The current version is a command-line application and has some limitations:

1. There is currently no username/password authentication.
2. Data is stored in a text file rather than a database.
3. The current file format stores names without spaces correctly only when they are treated as a single `%s` field during loading.
4. There is no graphical user interface.
5. There is no role-based access control.
6. There is no database backup mechanism.
7. The sorting implementation uses a fixed pointer array of size 100.

These can be addressed in future versions.
