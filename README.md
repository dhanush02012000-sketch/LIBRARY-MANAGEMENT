Library Management System (C)

A Library Management System implemented in C that allows users to:

Add, update, delete, and search books
View all available books
Issue and return books
Maintain issued book records
Save and load data using text files
Store records dynamically using linked lists
Menu-driven console interface

Technologies Used:

C Programming
Linked Lists
File Handling
Structures
Dynamic Memory Allocation
GCC/Makefile

Key Features:

Book inventory management
User-friendly search by ID, title, or author
Book issue and return tracking
Fine calculation for late returns
Persistent storage using books.txt and issued.txt
Automatic data loading and saving
